# solar-landing-page

Landing page tư vấn điện mặt trời mái nhà.

## Hotline
0916 85 85 66

## Logo
- Kích thước file thiết kế đề xuất: **800 × 250 px**
- Desktop hiển thị khoảng: **220 × 70 px**
- Mobile hiển thị khoảng: **160 × 52 px**

## Chức năng hiện có
- Responsive desktop/tablet/mobile
- CTA đăng ký mở popup
- Hotline click-to-call
- Form validation số điện thoại
- Lưu UTM source/medium/campaign/content/term vào form
- Form đang ở demo mode và lưu payload tạm vào localStorage
- Có điểm nối sẵn để tích hợp CRM/API ở phase 2
- Công cụ ước tính nhanh theo mức hóa đơn điện

## Triển khai
Static site, phù hợp GitHub Pages.

## Ghi chú
Nội dung/giao diện là phiên bản triển khai mới bám theo mô hình landing page chuyển đổi của trang tham khảo, không sao chép mã nguồn hoặc tài sản thương hiệu của bên thứ ba.
